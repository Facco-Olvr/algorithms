# 📅 Anotações — 14/10: Passagem de Parâmetros

## 📌 Conceitos Básicos
* **Formas de passagem de parâmetro:** cópia, referência (`&`) e ponteiro (`*`).
* **`&` (Referência):** representa o endereço local de memória da variável.
* **`*` (Ponteiro):** aponta para um endereço de memória.

---

## 💻 Exemplos Práticos

### 1. Passagem por Cópia (Valor)
Quando não usamos o `&`, a função recebe apenas uma **cópia** do valor original. Alterações feitas dentro da função não afetam a variável na `main`.

```cpp
void adiciona(int x) {
    x = x + 1;
}

int main() {
    int a = 5;
    adiciona(a);
    cout << a; // Saída: 5 (o valor original não mudou)
}
```

Nota: Para que o resultado no terminal fosse 6, seria necessário colocar o & ao lado do parâmetro (int &x).

2. Comparação: Sem Referência vs. Com Referência

```
void semRef(int x)  { x = 10; }
void comRef(int &x) { x = 10; }

int main() {
    int a = 5;
    int b = 5;

    semRef(a); // 'a' continua valendo 5
    comRef(b); // 'b' passa a valer 10
}
```
* **Conclusão:** O operador `&` permite que a função altere diretamente o valor da variável original declarada na `main`[cite: 4].
* **Aplicações práticas:** Ideal para situações em que a função precisa modificar o estado de uma variável externa — como zerar contadores, incrementar valores (`+1`) ou atualizar pontuações[cite: 4].
