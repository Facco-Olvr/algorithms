# Anotações de Aula — 14/09: Leitura de Arquivos em C++

## 📚 Conceitos Teóricos

- **Sistema Computacional e Memória:**
  - **Memória Principal (RAM):** Armazena variáveis e programas em execução (volátil).
  - **Memória Secundária (Disco):** Armazena dados de forma permanente através de arquivos (`JSON`, `CSV`, `SGBD`, `.txt`).
- **Biblioteca `<fstream>`:** Biblioteca padrão necessária para manipulação de arquivos de entrada e saída[cite: 8].
- **Tipos e Métodos Principais:**
  - `ifstream`: Tipo de fluxo de entrada utilizado para leitura de arquivos[cite: 8].
  - `open(nomeArquivo)`: Abre o arquivo especificado (é comum solicitar o nome ao usuário via `getline`)[cite: 8].
  - `eof()` (*End of File*): Retorna `true` quando atinge o fim do arquivo, útil para controlar laços de leitura[cite: 8].
  - `close()`: Libera e fecha o recurso do arquivo ao finalizar as operações[cite: 8].

## 💻 Exemplo Prático: Leitura de Arquivo

O código abaixo solicita o nome do arquivo ao usuário, verifica a existência e lê todo o conteúdo linha por linha até o final (`eof`):

```cpp
#include <iostream>
#include <fstream>
#include <string>
#include <cstdlib> // Necessário para usar exit()

using namespace std;

int main() {
    // Solicita ao usuário o nome do arquivo de origem
    string nomeArquivo;
    cout << "Informe nome do arquivo que quer exibir na tela: ";
    getline(cin, nomeArquivo);

    // Abre o arquivo para leitura
    ifstream procuradorArquivo;
    procuradorArquivo.open(nomeArquivo);

    // Verifica se o arquivo foi localizado/aberto com sucesso
    if (!procuradorArquivo) {
        cout << "Arquivo não localizado. Programa encerrado." << endl;
        exit(0);
    }

    cin.ignore(); // Limpa o buffer se necessário

    // Lê o arquivo capturando as linhas
    string linha;
    while (!procuradorArquivo.eof()) { // Enquanto não estiver no fim do arquivo
        getline(procuradorArquivo, linha); // Lê a linha inteira
        
        // Alternativa: procuradorArquivo >> frase; // Lê palavra por palavra da linha
        
        cout << linha << endl;
        // Tratar a linha e extrair dados dela
    }

    // Fecha o arquivo liberando recursos
    procuradorArquivo.close();

    return 0;
}
