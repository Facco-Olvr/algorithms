## Conceitos e Bibliotecas

* **`push_back`**: Permite adicionar novos elementos ao vetor sem precisar definir seu tamanho antecipadamente. O vetor funciona de maneira dinâmica e cresce conforme novos dados são inseridos.
* **`vetor.size()`**: Retorna a quantidade de elementos existentes no vetor. Como o tamanho do vetor dinâmico pode variar, o `size()` é utilizado na condição do `for` para percorrer todos os elementos.
* **`#include <string>`**: Permite trabalhar com textos e cadeias de caracteres.
* **`#include <vector>`**: Permite utilizar vetores dinâmicos.

## Definindo Structs com `typedef`

Estrutura base utilizada para representar registros (como no exemplo de garagem/estacionamento):

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

typedef struct {
    string placa;
    string cor;
    string horaEntrada;
    string horaSaida;
} Veiculo;

int main() {
    vector<Veiculo> garagem; // Vetor dinâmico de estruturas
    return 0;
}
