# Anotações de Aula — Modularização e Funções em C++ (28/09)

## 📚 Conceitos Teóricos

### 1. Modularização de Código
- **Por que utilizar?**
  - Melhora a manutenção do código.
  - Mantém o arquivo principal (`main.cpp`) limpo e organizado.
  - Permite reutilizar a mesma função/operação em vários programas diferentes.
- **Cabeçalhos Customizados (`.h`):**
  - As funções genéricas podem ser isoladas em arquivos de cabeçalho (ex: `util.h`).
  - No programa principal (`main.cpp`), importa-se o arquivo usando `#include "util.h"` (com aspas duplas para arquivos locais).

---

### 2. Métodos sem Retorno (`void`)
- Utilizam a palavra-chave `void` na sua assinatura.
- **Objetivo:** Executam apenas uma ação ou procedimento na tela sem devolver um valor diretamente para quem chamou.

#### Exemplo Prático 1: Contar ocorrências de uma letra (Função `void`)

**Arquivo `util.h` (Função Procedural):**
```cpp
void receberPalavraLetra(string palavra, char letra) { // Não retorna valor
    cout << "digite a palavra: ";
    cin >> palavra;

    cout << "digite a letra: ";
    cin >> letra;

    int contador = 0;
    for (int i = 0; i < palavra.size(); i++) {
        if (palavra[i] == letra) {
            contador++;
        }
    }

    cout << "A letra '" << letra << "' aparece " << contador << " vez(es) na palavra \"" << palavra << "\".\n";
}
```
Arquivo main.cpp:
```cpp
#include <iostream>
#include <string>

using namespace std;

#include "util.h"

int main() {
    string palavra;
    char letra;

    receberPalavraLetra(palavra, letra);

    return 0;
}
```
3. Métodos com Retorno (Funções com return)
Devolvem um valor do tipo especificado (int, bool, string, float, etc.) para o ponto onde a função foi chamada usando a instrução return.

Objetivo: Processar uma informação e fornecer um resultado computado para ser armazenado em variável ou utilizado em expressões.
