## Geração de Números Aleatórios

Para trabalhar com valores randômicos em C++, precisamos incluir duas bibliotecas essenciais:

* **`#include <cstdlib>`**: Contém a função `rand()`
* **`#include <ctime>`**: Contém a função `time()`, usada para definir a semente aleatória

### Exemplo de Uso:

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>

using namespace std;

int main() {
    srand(time(0)); // Garante que os números gerados sejam diferentes a cada execução
    
    int vetor[5];
    for (int i = 0; i < 5; i++) {
        vetor[i] = rand() % 100; // Gera números aleatórios de 0 até 99
    }

    return 0;
}
```

## Práticas de Estrutura de Menu

Estrutura padrão utilizando `do-while` e `switch-case` para interação no terminal:

```cpp
int opcao;
do {
    cout << "--- MENU ---" << endl;
    cout << "1. Opcao 1" << endl;
    cout << "2. Opcao 2" << endl;
    cout << "0. Sair" << endl;
    cout << "Escolha uma opcao: ";
    cin >> opcao;

    switch (opcao) {
        case 1:
            // Lógica da opção 1
            break;
        case 2:
            // Lógica da opção 2
            break;
        case 0:
            cout << "Saindo..." << endl;
            break;
        default:
            cout << "Opcao invalida!" << endl;
    }
} while (opcao != 0);
```
