# ⚔️ RPG em Terminal (C++)

Projeto pessoal em desenvolvimento para praticar conceitos de **Programação Orientada a Objetos (POO)**, estruturas condicionais e laços em C++.

---

## 🎯 Objetivos do Projeto

- Aplicar conceitos de POO em C++ (Classes, Objetos, Encapsulamento).
- Criar um sistema de combate em texto interativo via terminal.
- Gerenciar atributos de personagens (Vida, Ataque, Defesa, Experiência).

---

## 🛠️ Como Executar

```bash
# Compilar o código
g++ main.cpp -o rpg

# Executar
./rpg
