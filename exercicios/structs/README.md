## 📚 O que é uma `struct`?

Em C/C++, uma `struct` (estrutura) é um tipo de dado personalizado definido pelo programador que permite agrupar variáveis de tipos diferentes sob um mesmo nome.

```cpp
struct Pessoa {
    string nome;
    int idade;
    float altura;
};
